# Exchange-quarter-countdown
This is a project built for [Your Deadline, Your Design: Create a Countdown Lock Screen challenge held by Handshake]([https://handshake.com](https://app.joinhandshake.com/learn/your-deadline-your-design-create-a-countdown-lock-screen-e748e649/mission_step_cmvqrpa9a0aiw22ubfo7ebelc)). 

A simple Super Mario style countdown and reminder for my soon-to-be-ending exchange. Includes customized dates and bucket list, and can generate a lock screen mobile wallpaper. To make more fun I set some coins for each reminder completed. 

It can be extended to a general semester planner, as I did not really put many exchange-unique elements in it.
